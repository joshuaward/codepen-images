4. A financial company has recently expanded globally and wants to build an AI-assisted chat application to scale customer service capacity. The company is subject to multiple regulations and compliance frameworks. The company must incorporate responsible AI principles into the solution.

Which approaches align with responsible AI principles? (Select TWO.)

Test responses for data leakage

Correct. Data privacy and security are a component of responsible AI. Customer data includes personally identifiable information (PII) that can identify an individual from the data. Company privacy policies and regulations require PII to be protected. To redact PII through removal or obfuscation avoids the risk that model predictions might leak information about customers in the training dataset. Models trained on datasets that contain sensitive data such as PII should be tested to ensure that the sensitive data is not leaked in the response.

Monitor responses for bias

Correct. Fairness is a component of responsible AI. Biases in ML include group-based data imbalances or differences in model performance across groups. Bias in an ML system can cause negative impacts on affected groups. A model can initially produce biased predictions if training data contains imbalances or labeling biases between groups. Additionally, model performance can drift over time if the training data is no longer representative of the production dataset. Drift can occur because of temporary or permanent changes in the customer base or in customer behaviors.

12. Which factors can impact the latency of invoking a large language model (LLM)? (Select TWO.)

Number of tokens in the prompt

Correct. The longer the input prompt, the more processing is required by the LLM before the LLM can output the first token. The number of tokens in the input prompt will impact the latency of the LLM invocation.

Number of tokens in the response

Correct. LLMs generate one output token at a time. Therefore, each token indicates that the LLM needs to be invoked again. The number of tokens in the response will impact the latency of the LLM invocation.

Prompt engineering

Correct. Prompt engineering is a technique to craft prompts in a way that helps an FM improve the format of responses. This technique does not require any additional resources. Therefore, this is the most cost-effective solution to improve the format of responses. Additionally, this technique is recommended as the first step to try to improve the format of FM responses.

60. An ML engineer wants to improve the performance of a large language model (LLM) while keeping the costs low.

Select and order the model improvement techniques from the following list from MOST cost-effective to LEAST cost-effective. Each model improvement technique should be selected one time. (Select and order THREE.)

Retrieval augmented generation (RAG)
Prompt engineering
Instruction-based fine-tuning

WRONG

Prompt engineering (MOST cost-effective)

Retrieval augmented generation (RAG)

Instruction-based fine-tuning (LEAST cost-effective)

Prompt engineering provides techniques that you can use to modify and optimize prompts. The prompts are sent to an LLM to increase the likelihood of the LLM providing a high-quality response. Prompt engineering does not require any additional infrastructure. Therefore, prompt engineering is the most cost-effective approach to improve the quality of LLM responses in the near term.

RAG includes an embedding model and a vector database that can perform similarity search of embedded prompts against the embeddings in the database. RAG can provide valuable context to an LLM to reduce the odds of the LLM hallucinating or lacking relevant information. RAG has additional costs for the use of an embedded model and a vector database. Therefore, RAG is not as cost-effective as prompt engineering.

Instruction-based fine-tuning uses labeled data to provide an LLM with additional training. Therefore, instruction-based fine-tuning can improve the quality of LLM responses. Data labeling and additional training require additional costs. Therefore, instruction-based fine-tuning is less cost-effective than RAG implementation.

65. Which inference parameters affect the responses of a prompt? (Select TWO.)

Temperature

Correct. Temperature is a parameter that controls the randomness and creativity of large language model (LLM) responses. The higher the temperature, the more randomness in the output.

Top_p

Correct. Top_p is a parameter that controls the sample size of the pool and the most likely candidates that a model considers for the next token. Top_p can affect the responses of a prompt. A lower value will decrease the size of the pool. A higher value will increase the size of the pool.
